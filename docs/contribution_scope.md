# 본인 기여와 팀 역할

## 본인 역할

PM으로 프로젝트 일정을 조율하고 핵심 기능을 제안했으며 시스템 설계와 백엔드 개발을 담당했습니다. 후배 팀원들과 함께 진행한 프로젝트로, 프런트 개발 방향과 백엔드 연계에 대한 지도·지원도 수행했습니다.

| 영역 | 본인 기여 | 확인 기준 |
|---|---|---|
| PM | 일정 조율·핵심 기능 제안 | 사용자 확인 |
| 시스템 설계 | 서비스 구성과 데이터 흐름 설계 | 사용자 확인 및 현재 코드 구성 |
| 백엔드 | FastAPI·공공 API 연동·좌표 및 시각 처리·응답 변환 | 사용자 확인 및 back-end 소스 |
| 개발 지도 | 후배 팀원 프런트 개발 방향과 데이터 연계 지도·지원 | 사용자 확인 |

## 팀원 역할과 프런트 소스

프런트 화면 구현은 팀원의 기여로 구분합니다. 함께 보관한 `front-end`는 날씨·유동인구·지도 기능이 백엔드와 어떻게 연결되는지 설명하는 팀 프로젝트 소스입니다. 전체 프런트를 본인이 단독 구현한 것으로 서술하지 않습니다.
