# 구현 범위

## 주요 구현

날씨 API, 인구 API, 네이버 지도와 지역·시설 검색, 지역 상태 공유, 지도 마커·상세 패널의 연결 코드가 있습니다. 백엔드는 기준 좌표와 실시간 응답을 결합하며 학습된 자체 모델·사용자 계정 DB는 사용하지 않습니다.

## 표현할 때 구분할 사항

- 실시간 정보는 제공기관의 측정·발표 데이터입니다. WebSocket 스트리밍이나 시설 자체 센서 계측을 구현한 것으로 설명하지 않습니다.
- 시설 상세의 혼잡도는 가장 가까운 인근 측정지역 정보입니다.
- 프런트의 Q&A는 향후 안내 연결용 패널입니다. 현재 챗봇 기능은 없습니다.
- 정부24는 외부 페이지 연결입니다. 주민센터 등의 운영 시간·프로그램 정보는 메뉴 설명만으로 별도 수집 완료 기능으로 확대하지 않습니다.
- `subway_loader.py`에는 미구현 함수가 있으며 현재 인구 조회 흐름에 쓰이지 않습니다. `mapper.py`의 과거 다각형 매핑 함수도 현재의 거리 기반 서비스 호출 흐름과 분리합니다.
- `deploy.tar.gz`는 원본 폴더에 남은 패키징 산출물입니다. 공개 사본에는 포함하지 않았으며 파일 존재만으로 실제 서비스 운영 완료를 단정하지 않습니다.

## 공개 정리 방식

현재 소스의 기능과 파일명을 유지하고 실행에 필요한 작은 기준 데이터·설정 예시를 함께 보관했습니다. 개발 도구 설정, 바이트코드, 실인증 파일과 기존 Git 이력은 복사하지 않았습니다. 별도 성능 측정값·사용자 수·멘토링 효과 수치를 만들지 않았습니다.
