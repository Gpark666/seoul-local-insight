# 서울 지역 생활정보 지도

현재 위치 또는 검색 지역의 날씨·유동인구·주변 생활시설을 연결하는 서비스입니다. 저는 PM으로 시스템 설계·핵심 기능 제안·일정 조율을 담당하고 백엔드를 구현했습니다. 후배 팀원들과 협업하며 프런트 개발 방향과 백엔드 데이터 연계를 지도·지원했습니다.

## 서비스 목적

날씨, 주변 혼잡도, 주민센터·운동시설·공원·지하철 등의 위치를 한 서비스에서 확인할 수 있도록 구성했습니다. 좌표를 공통 입력으로 사용해 서로 다른 제공기관의 데이터를 연결합니다.

## 직접 담당한 백엔드

FastAPI에 `/api/v1/weather/current`와 `/api/v1/population/nearby`를 구성했습니다. 날씨는 기상청 격자 좌표와 발표 시각을 계산해 관측·예보를 조회하고 공통 응답 구조로 변환합니다. 체감온도는 기온·습도·풍속에 따른 공식으로 계산합니다.

인구는 기준 장소 좌표에서 반경 내 측정지역을 찾은 뒤 서울시 실시간 데이터를 조회합니다. 여러 지역은 비동기로 요청하고, 일부 요청 실패 시에도 성공 결과를 유지합니다. 동일 지역 응답은 5분 메모리 캐시로 재사용합니다.

## 시스템 설계와 협업

서비스 흐름을 지역 선택 → 외부 데이터 조회 → 공통 응답 변환 → 화면 표시로 구성했습니다. 시스템 설계와 기능 제안, 일정 조율은 본인의 PM 역할입니다. 프런트 화면 구현은 팀원의 기여이며, 본인은 후배 팀원의 개발 방향과 백엔드 연계를 지도·지원했습니다.

## 데이터와 구현 범위

기준 장소 JSON에는 좌표를 확보한 110개 지역이 있습니다. 미해결 11개는 별도 파일로 남아 있습니다. 시설의 혼잡도는 가까운 측정지역 정보이며 개별 시설 자체의 이용자 수를 계측한 값이 아닙니다. 자체 AI 학습 모델 없이 공공 API 데이터와 계산 로직으로 구성한 서비스입니다.

## 개발 기록

원본 Git 기록은 2026년 8월 11일~8월 20일이며, 백엔드 주요 커밋은 8월 17일부터 확인됩니다. 공개용 사본 정리일은 2026년 11월 24일입니다.
